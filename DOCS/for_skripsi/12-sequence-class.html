Sequence diagram dan class diagram

Sequence diagram menunjukkan urutan pesan antara peramban, API, dan basis data, termasuk SET LOCAL ROLE per request. Class diagram menggambarkan kelas domain inti dan operasinya (opsional karena ERD sudah ada).

Sequence diagram

sequenceDiagram
    autonumber
    actor P as Pengguna
    participant W as Web (app.js)
    participant A as API FastAPI
    participant DB as PostgreSQL (monitor_public)
    P->>W: isi username & sandi, klik Masuk
    W->>A: POST /api/auth/login
    A->>DB: BEGIN#59; SET LOCAL ROLE monitor_public
    A->>DB: SELECT * FROM auth_get_user(username)
    DB-->>A: user_id, password_hash, is_active, locked_until
    A->>A: bcrypt.verify(sandi, hash)
    alt sandi benar dan akun aktif
        A->>DB: auth_record_login(user_id, true)
        A->>DB: INSERT user_activity_logs (LOGIN_SUCCESS)
        A-->>W: 200 + cookie orbit_u_session (JWT 8 jam)
        W->>A: GET /api/auth/session
        A-->>W: role_code, permissions
        W-->>P: menu sesuai peran
    else sandi salah / akun terkunci
        A->>DB: auth_record_login(user_id, false)
        A->>DB: INSERT user_activity_logs (LOGIN_FAILED)
        A-->>W: 401 INVALID_CREDENTIALS / 423 ACCOUNT_LOCKED
        W-->>P: dialog galat
    end

sequenceDiagram
    autonumber
    participant S as Scheduler (APScheduler)
    participant H as HydrometJob
    participant G as NASA GES DISC / LANCE
    participant DB as PostgreSQL (monitor_etl)
    participant AE as AlertEngine
    participant F as ForecastStore
    S->>DB: pg_try_advisory_lock('orbit-u:hydromet')
    DB-->>S: true
    S->>H: run()
    H->>DB: tanggal belum COMPLETED
    loop setiap tanggal
        H->>G: unduh GPM Final → Late → Early
        G-->>H: granule harian
        H->>H: akumulasi 24h/72h/7d/30d, agregasi zonal
        H->>DB: UPSERT region_observations
        H->>AE: evaluate(tanggal)
        AE->>DB: INSERT alert_events (ON CONFLICT DO NOTHING)
        H->>G: unduh MODIS (tidak fatal)
        H->>DB: UPDATE dataset_jobs status COMPLETED
    end
    H->>F: refresh()
    F->>DB: band_forecasts, points, scores
    S->>DB: pg_advisory_unlock
