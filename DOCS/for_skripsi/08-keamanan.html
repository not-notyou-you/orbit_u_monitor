Keamanan, VIEW, indeks, dan redundansi terkendali

Matriks GRANT, policy, trigger, dan indeks di halaman ini dibaca langsung dari katalog PostgreSQL (information_schema, pg_policies, pg_indexes), jadi sama persis dengan database yang berjalan.

Matriks GRANT

S = SELECT, I = INSERT, U = UPDATE, D = DELETE. Hak yang tercantum adalah hak langsung; peran di atas mewarisi hak peran di bawahnya.

Row-level security dan fungsi autentikasi

FungsiDipakai untuk
auth_get_user(username)Ambil hash dan status kunci saat login
auth_record_login(user_id, success)Catat hasil verifikasi; 5 gagal beruntun → kunci 15 menit
auth_session_user(user_id)Peran dan status terkini setiap request
auth_get_token(prefix)Cari token Bearer sebelum pemiliknya diketahui
auth_change_own_password(hash)Ganti sandi sendiri; baris ditentukan app.user_id
auth_register_user(username, email, hash)Registrasi mandiri; peran dikunci USER di dalam fungsi
